## Локальный запуск модуля

Для запуска модуля локально нужно:
- настроить **.env** файл (можно скопировать **.env.example**)
- запустить приложение
    ```shell
    npm i
    ```

Модуль будет доступен по 3001 порту (`http://localhost:3000`).

## Проверка качества кода

Для запуска линтера и проверки типов можно воспользоваться командой:
```shell
npm run check
```

Для автоматического исправления ошибок линтера и повторной проверки типов:
```shell
npm run check:fix
```
